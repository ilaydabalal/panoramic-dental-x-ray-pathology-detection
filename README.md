# panoramic-dental-x-ray-pathology-detection
Clinical Decision Support System (CDSS) powered by YOLOv11 and Streamlit for multi-class automated dental pathology and structure detection on panoramic radiographs. Panoramik diş röntgenlerinde YOLOv11 mimarisiyle 15 farklı patoloji ve yapıyı otomatik tespit eden, Streamlit tabanlı klinik karar destek ve raporlama sistemi.
